# COMPASS 課題

## 実装方針

### 言語/実行環境
- Go 言語を使用する。
  - JVM 系言語はまだ経験が少ないため。
- マルチステージビルドで、`golang` イメージでAPIを静的ビルドし、`scratch` イメージで実行する。通常起動には `compose.yaml` を使う。
- ローカル開発時は `compose.dev.yaml` を明示的に重ねる。APIのソースをマウントし、Goファイルの変更時に Air で再ビルド・再起動する。MySQLとHTTPSの設定は通常起動と共通にする。

### アーキテクチャ
- [アーキテクチャ設計](ARCHITECTURE.md)に記載。

### フィルター/ソート/レスポンス
- 検索条件が複数指定された場合はAND条件にする。
- 生徒名でソートする場合、同名の生徒は生徒IDの昇順で並べる。
- 該当件数が0なら本文なしの `404`、指定ページだけが範囲外なら `200` で返す。不正なクエリにはエラーメッセージ付きの `400` を返す。

### TLS
- ローカル用の自己署名証明書を初回起動時に生成し、GoのHTTPサーバーでTLSを終端する。

### テスト
- 以下のテストを用意し、自動で実行できるようにする。
  - ユニットテスト
    - DBを使用せず、必要に応じてモックを使用する。
  - HTTPテスト
    - `httptest` を使用してAPI単位でテストする。
    - テスト用のMySQLを使用する。
