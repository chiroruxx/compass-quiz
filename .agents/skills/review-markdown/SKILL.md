# Markdown のレビュー

1. 依頼された Markdown ファイルを確認する。実装ステップのレビューでは、そのステップで変更した Markdown を対象とし、変更箇所の前後も読んで文脈や既存の文体を確認する。
2. 誤字脱字、助詞（てにをは）、文の係り受けを確認する。語句の表記、文末の調子、句読点を確認し、文書内の既存の方針に合わせる。引用、コード、識別子などは原文の表記を保つ。
3. 長い文章に複数の話題や手順が詰まっている場合は、話題ごとに意味のある見出しを付け、列挙や手順をリストにする。条件、例外、手順の順序は、それぞれが関係する記述と一緒に保つ。
4. 原意を保てる修正はファイルに反映する。要件、根拠、断定の強さなどが変わる場合や、意図が読み取れない場合は、その箇所を人間に差し戻す。
5. 差分を読み返し、意味が保たれていることと、変更した見出しへのリンクや Markdown の構造が有効であることを確認する。修正内容を要約し、人間の判断が必要な箇所はファイルと行、判断してほしい点を示す。
