1. 以下の要件を満たすWebサーバーを実装してください
2. Webサーバーを `docker compose up` で起動できるようにしてください
    1. この時ローカル側のポートフォワーディングは `48080` を指定してください
       2.課題1のMySQLと同時に起動できるようにしてください
3. 実装方針、アーキテクチャ、補足説明などをREADME.mdに記述してください

# 要件

## 実装言語候補

- Scala
- Java
- Kotlin
- Go

## API仕様

### エンドポイント

```
GET /students
```

### リクエスト

| パラメタ名       | 型       | require/optional | default | 概要                                                                                                                                                                   |
|------------------|----------|------------------|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `facilitator_id` | `int`    | `require`        |         | 教師ID                                                                                                                                                                 |
| `page`           | `int`    | `optional`       | `1`     | ページネーションのページ数。                                                                                                                                           |
| `limit`          | `int`    | `optional`       | `5`     | ページネーションの1ページあたりの表示数。                                                                                                                              |
| `sort`           | `string` | `optional`       | `id`    | ソートのキーとしてレスポンスにある以下のフィールドを指定できる<br>・`id`: 生徒ID<br>・`name`: 生徒名<br>・`loginId`: ログインID                                        |
| `order`          | `string` | `optional`       | `asc`   | ソートの昇順=`asc`、降順=`desc`を指定する                                                                                                                              |
| `{key}_like`     | `string` | `optional`       |         | 指定したレスポンスのフィールドによる部分一致検索をします。<br>`{key}`にはレスポンスにある以下のフィールドを指定できる。<br>・`name`: 生徒名<br>・`loginId`: ログインID |

### リクエスト例

```shell
curl 'https://127.0.0.1:48080/students?facilitator_id=1'
```

### レスポンス

| フィールド                     | 型       | 概要                           |
|--------------------------------|----------|--------------------------------|
| `$.students`                   | `array`  |                                |
| `$.students[*].id`             | `int`    | 生徒ID                         |
| `$.students[*].name`           | `string` | 生徒名                         |
| `$.students[*].loginId`        | `string` | ログインID                     |
| `$.students[*].classroom`      | `object` |                                |
| `$.students[*].classroom.id`   | `int`    | クラスID                       |
| `$.students[*].classroom.name` | `string` | クラス名                       |
| `$.totalCount`                 | `int`    | リクエストの条件に該当する件数 |

### レスポンス例

```json
{
  "students": [
    {
      "id": 1,
      "name": "佐藤",
      "loginId": "foo123",
      "classroom": {
        "id": 1,
        "name": "クラスA"
      }
    }
  ],
  "totalCount": 1
}
```

### エラー

エラーの場合にレスポンスボディは不要です。
以下に定義されていないエラーは、必要に応じて適宜レスポンスを定義してください。

| 状況                                 | レスポンスコード  |
|--------------------------------------|-------------------|
| リクエストに該当する生徒が存在しない | `404 Not Found`   |
| リクエストに問題がある               | `400 Bad Request` |
