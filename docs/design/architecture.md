# スキーマ駆動
スキーマと実装の乖離を防ぐため、スキーマ駆動を利用します。
主に以下の2点で行います。

- OpenAPIをもとにGinのエンドポイントを生成する。
- SQLをもとにクエリ実行関数を生成する。

# フラットパッケージ / レイヤードアーキテクチャ

対象となるドメイン領域が現時点であまり複雑でないことから、[フラットパッケージ](https://future-architect.github.io/articles/20201109/)を採用します。
この記事の厳密なものではなく、「同じパッケージに入れる」という部分のみ採用しています。

一方で、すべてを同じファイルに書くと煩雑になるため、レイヤー単位でファイルを切って管理します。
Go はパッケージ単位でしか可視性を制御できないため、不適切な依存関係のコードを書けてしまいますが、レビューなど開発プロセスの中でフォローします。
